# 🥑 Masakra CLI

Oficjalne narzędzie od bazy SucharyAPI do generowania satyrycznych wypowiedzi w terminalu

---

## 🚀 Instalacja

Zainstaluj `masakra` jedną komendą. Skrypt automatycznie rozpozna Twój system operacyjny oraz architekturę procesora, pobierze najnowszą binarkę i doda ją do zmiennej środowiskowej `PATH`.

### Linux / macOS

```bash
curl -sSL https://raw.githubusercontent.com/SucharyAPI/masakra-cli/main/install.sh | sh
```

### Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/SucharyAPI/masakra-cli/main/install.ps1 | iex
```

---

## 💻 Użycie

Uruchom program bez argumentów, aby wylosować kawał:

```bash
masakra
```

Możesz także podać liczbę naturalną jako argument, aby otrzymać określoną liczbę masakr:

```bash
masakra <liczba>
```

### 📝 Przykłady

```bash
masakra 2
masakra 30
```

---


## ℹ️ Informacje dodatkowe
**1.** Maksymalna liczba masakr do wygenerowania na raz to 100
